# Code of Conduct

We are committed to a respectful, harassment-free community. Be considerate, accept constructive feedback, and focus on what is best for the project. Harassment, discrimination, personal attacks, and publishing others' private information are not tolerated.

Maintainers may remove contributions or restrict participation for conduct that violates these standards. Report concerns to the maintainer through the contact listed on the GitHub profile.

This policy is adapted in spirit from the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
